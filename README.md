# Telop Studio 2

9:16のショート動画用に、透過PNGのテロップを作るWebアプリです。台本を貼り付けると話者ごとにデザインがそろい、強調したい文字だけを装飾して、1080×1920の位置込みPNGでまとめて書き出せます。

アプリ：https://sakrainari.github.io/telopstudio2/

ビルドもインストールも不要です。HTML / CSS / JavaScript（ES Modules）だけで動きます。

[Telop Studio](https://github.com/sakrainari/telopstudio)（初代）を、ショート専用として一から組み直した版です。

## 使い方

1. **台本を入れる**：左の「台本から追加」に貼り付けます。空行で次のテロップに分かれ、行の頭の `A:` `B:` `N:` `※` `!` で話者が決まります。
2. **見た目を決める**：右の「話者全体」で、話者ごとのフォント・色・フチ・影・座布団を決めます。
3. **位置を決める**：中央の9:16画面で、テロップをドラッグします。「話者全体」なら同じ話者すべて、「このテロップ」ならその1枚だけが動きます。矢印キーでも動かせます（Shiftで大きく）。細かく合わせたいときは、右上の＋で拡大できます（「全体」で元に戻ります）。
4. **一部だけ目立たせる**：入力欄で文字を選ぶと、右側が自動で「選んだ文字」に切り替わります。下の「重要」「赤」「大きく」などで装飾できます。
5. **書き出す**：右上の「書き出し」から、1枚ずつコピー・保存するか、まとめてZIPで保存します。

### ショートのための機能

- **自動折り返し**：設定した幅を超えると、単語の切れ目で折り返します。句読点や「」の行頭・行末の禁則も守ります。最大行数を超える場合は、自動で縮小できます。
- **1080×1920の位置込み書き出し**：編集ソフトに置くだけで、プレビューと同じ位置になります。文字だけを切り抜いたPNGも選べます。
- **アプリのUIを避けるガイド**：YouTubeショート・TikTok・リールのボタンや説明文がかかりやすい範囲を表示します。テロップがはみ出すと、画面の下に警告が出ます。範囲は目安なので、「実画面を重ねる」で実際のスクリーンショットを重ねて確認してください。はみ出しの判定は、実際に色が付く部分（文字の形とフチ、座布団）で行います。影や全角記号の余白は含みません。
- **実機プレビュー**：Pixel 8 Pro・Pixel 8・iPhone 15/16・Galaxy S24・iPhone SEの画面の形で確認できます。縦長のスマホでは、動画が「横幅に合わせて上下に余白」が出る場合と、「画面を埋めて左右が切れる」場合があるので、両方を切り替えて確認できます。左右が切れてテロップが欠けるときは警告が出ます。
- **実機プレビュー**：Pixel 8 Pro・Pixel 8・iPhone 15/16・Galaxy S24・iPhone SEの画面の形で確認できます。縦長のスマホでは、動画が「横幅に合わせて上下に余白」が出る場合と、「画面を埋めて左右が切れる」場合があるので、両方を切り替えて確認できます。左右が切れてテロップが欠けるときは警告が出ます。

### キーボード

| キー | 動作 |
| --- | --- |
| Ctrl+Enter | 同じ話者で次のテロップを追加 |
| Alt+↑ / Alt+↓ | 前 / 次のテロップへ |
| Ctrl+Z / Ctrl+Shift+Z | 元に戻す / やり直す |
| 矢印キー（テロップを選択中） | 位置を微調整 |
| Ctrl+マウスホイール（プレビュー上） | プレビューを拡大・縮小 |

### データの保存

- 作業内容はこのブラウザに自動保存されます。別のPCやブラウザへ移すときは、プロジェクトメニュー（…）の「JSONで保存」を使ってください。
- 初代Telop StudioのJSONも読み込めます。装飾は引き継がれ、折り返しと位置はTelop Studio 2の標準になります。
- 自分のフォントは、右の「フォント」→「＋ 自分のフォントを追加」→「PCのフォントから選ぶ」で、PCに入っているフォントを見本付きの一覧から選べます（Chrome・Edge。初回だけフォントの読み取りを許可します）。フォントファイルの読み込みや、名前での追加もできます。
- 追加したフォントはこのブラウザだけに保存されます。JSONにはフォント名だけが入ります。

## ローカルで開く

ES Modulesを使うため、ファイルを直接開くのではなく、HTTPサーバー経由で開きます。

```sh
python -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。GitHub Pagesでは、Settings → Pages → Deploy from a branch → main / (root) で公開できます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `js/style.js` | デザインの項目・初期値・サンプル、読み込み値の検証 |
| `js/text.js` | 見た目の1文字の扱い、台本の分割、自動強調、折り返し位置 |
| `js/render.js` | レイアウトと描画（フチ・影・座布団・縮小）、位置込み／切り抜き |
| `js/store.js` | プロジェクト・自動保存・元に戻す・変更通知・JSON読込（初代の変換を含む） |
| `js/fonts.js` | 内蔵フォントと追加フォント |
| `js/zip.js` | ZIP作成（外部ライブラリなし） |
| `js/ui/*.js` | 画面ごとの処理。互いを直接呼ばず、`store.js` の通知で動きます |

## テスト（開発用）

アプリ本体には不要です。Node.jsとPlaywrightで、ブラウザ操作の回帰テストを実行します。

```sh
npm install --prefix ../telop-test-tools playwright
TELOP_PLAYWRIGHT_PATH=../telop-test-tools/node_modules/playwright node tests/regressions.cjs
```

Chromeを指定する場合は `TELOP_CHROME_PATH` を、テストを絞る場合は `TELOP_TEST_FILTER='^3:'` のように指定します。
